## 已精簡與合併

1. 導航中四份相同的「開始指定模式→顯示測驗」分支合併。
2. 收藏頁移除獨立 `RARITY_CLASS`，與寶箱共用資料層的 `RARITY_STYLE`。
3. 移除只寫不讀的 `dailyAlreadyCleared`、未使用的 `wireSeg` 初值參數與回傳值、任務狀態的 `raw` 欄位。
4. 移除沒有外部呼叫者的 `Quiz.showResult`、`AudioKit.getContext`、`FX.splash` 匯出；函式本體仍供模組內部使用。
5. 原本未呼叫的 `setSegValue` 用來修復篩選狀態同步；原本只寫入的 `currentScreen` 用來判斷測驗離場，不誤刪必要行為。
6. 移除已由全域 `[hidden]` 規則涵蓋的 `.kana-replay[hidden]`，以及 README 重複的 quiz.js 檔案列。
7. 移除錯誤讀音 `ユウハモン` 的 manifest 對照，避免誤用舊音檔；59 題仍全部有可用的語音對照，共 58 個唯一讀音。

未把只有低文字引用次數的 CSS 選擇器直接當死碼刪除：本專案大量 class 是由 JS 組合產生，響應式、狀態樣式與 keyframes 也必須分開判斷。沒有足夠的瀏覽器覆蓋證據，不能安全宣告其餘樣式可刪。
