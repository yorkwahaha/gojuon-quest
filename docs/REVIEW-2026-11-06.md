## 無障礙與優化建議

1. 任務分頁的 `role=tab` 應使用 aria-selected，報告成立。已修正 selected、tabindex、tabpanel 關聯，支援左右方向鍵、Home 與 End。
2. 五種 dialog 原先缺少共用焦點管理，報告成立。已補上初始焦點、Tab／Shift+Tab 邊界循環與關閉後返回。全螢幕招式的繼續控制也保留焦點，限時小格繼續正常作答。
3. 報告建議結果關閉後焦點返回「もう一回」，這個目標在關閉的 dialog 內。現在 Esc／背景關閉結果回首頁，焦點進入「馬上開始玩」。重玩按鈕本身執行重玩時則進入測驗畫面。
4. 另外修正升級 dialog 的 aria-labelledby 原先指向不存在的 levelupTitle，改指向 levelupRank。這是原報告漏列的問題。
5. 「首頁預載四張彩漫共約 3 MB」不成立。基線 HTML 兩個 img 都指向同一張 stand-rush.webp，其他圖由當前招式題的 prepareAttack 指定。首頁共用圖是 742,776 bytes，四張檔案合計 2,973,046 bytes。保留出題時預載，確保答對後可以顯示圖片。
6. q09 與 q19 同讀音但表記分別是スタンド與幽波紋，屬教學內容選擇。保留 59 題及既有題號／順序，語音去重處理共用資產。
7. CSS 的跨段覆寫不直接等於死碼。本輪只合併 reduced-motion，整體主題合併可另作專項檢查。
