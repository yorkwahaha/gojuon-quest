# 背景音樂補檔

將 MP3 直接放在本目錄，檔名區分大小寫。可只補部分檔案。

| 檔名 | 使用時機 |
|---|---|
| `home.mp3` | 首頁、五十音表、收藏、任務 |
| `quiz.mp3` | 聽音挑戰、自由練習、每日挑戰 |
| `timeattack.mp3` | 限時挑戰 |

音樂循環播放，音量預設 16%。玩家首次點擊或鍵盤操作後才啟動，換頁會切換曲目，切至背景分頁會暫停，返回後繼續。設定中的「背景音樂」可獨立開關並保存。

缺檔或無法解碼時保持安靜，原版沒有合成背景音樂。音效仍依自己的開關播放。補檔後重新整理頁面即可讀取，在 GitHub Pages 使用則需將檔案一併提交部署。

測試使用的暫存音檔不會隨專案發布。正式音樂需自行提供。
