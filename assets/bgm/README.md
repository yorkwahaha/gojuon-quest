# 背景音樂補檔

將 MP3 放在本目錄，檔名區分大小寫。可只補部分檔案。補檔後在專案根目錄執行 `node tools/generate-voice-pack.js --media-only`。

| 檔名 | 使用時機 |
|---|---|
| `home.mp3` | 首頁、五十音表、收藏、任務 |
| `quiz.mp3` | 選「全部」的聽音／自由練習，以及每日挑戰 |
| `timeattack.mp3` | 選「全部」的限時挑戰 |
| `jojo.mp3` | 單選 JOJO 題目；聽音、自由練習、限時挑戰皆適用 |
| `jjk.mp3` | 單選咒術迴戰題目；聽音、自由練習、限時挑戰皆適用 |

完整路徑依序為 `assets/bgm/home.mp3`、`assets/bgm/quiz.mp3`、`assets/bgm/timeattack.mp3`、`assets/bgm/jojo.mp3`、`assets/bgm/jjk.mp3`。

在出題設定切換作品時立即切換 BGM；作品專用曲優先於一般／限時曲。切回「全部」恢復該模式的曲目。每日挑戰固定混合兩作品，設定與 BGM 都會回到「全部」。首頁、五十音表、收藏及任務仍使用 `home.mp3`。

音樂循環播放，音量預設 16%。玩家首次點擊或鍵盤操作後才啟動，換頁會切換曲目，切至背景分頁會暫停，返回後繼續。設定中的「背景音樂」可獨立開關並保存。

缺檔或無法解碼時保持安靜。音效仍依自己的開關播放。GitHub Pages 發布時請一併提交音檔與更新後的 `js/media-manifest.js`。

測試使用的暫存音檔不會隨專案發布。正式音樂需自行提供。
