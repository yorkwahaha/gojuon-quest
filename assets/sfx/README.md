# MP3 音效補檔

將 MP3 直接放在本目錄，檔名區分大小寫。所有既有音效入口已接線，可逐一補檔。

| 檔名 | 使用時機 |
|---|---|
| `click.mp3` | 導覽、按鈕、返回等操作 |
| `place.mp3` | 放入假名拼字 |
| `correct.mp3` | 答對、姓名更新、開啟音效 |
| `wrong.mp3` | 答錯、金幣不足 |
| `unlock.mp3` | 解鎖卡片、一般開箱結果 |
| `fanfare.mp3` | 每日挑戰完成 |
| `tick.mp3` | 限時挑戰倒數 |
| `star.mp3` | 其他結算 |
| `coin.mp3` | 金色加碼題答對 |
| `levelup.mp3` | 升級、連擊慶祝 |
| `claim.mp3` | 領取任務獎勵 |
| `crack.mp3` | 開箱敲擊，每次敲擊各播放一次 |
| `legendary.mp3` | SSR 開箱結果 |
| `cutin.mp3` | 彩漫招式攻擊 |

優先播放 MP3。缺檔、解碼失敗、播放拒絕或 1.5 秒仍無法開始時，回到該事件原有的合成音效。缺檔與逾時會記錄至本次頁面關閉，避免反覆請求。補檔後重新整理即可重試。

關閉「音效」會停止正在播放的 MP3 並取消待播回退。BGM 與朗讀發音有各自開關。建議素材去除開頭靜音，短音效保持精簡。

朗讀題目的語音繼續使用 `assets/voice/` 與既有瀏覽器語音備援，與此目錄分開。
