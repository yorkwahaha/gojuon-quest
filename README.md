# 五十音クエスト（五十音大冒險）

[線上遊玩](https://yorkwahaha.github.io/gojuon-quest/) · [GitHub 原始碼](https://github.com/yorkwahaha/gojuon-quest)

アニメのキャラクター名・わざ名をならべかえて、ひらがなとカタカナを楽しく覚える 小学生向け日本語学習ゲーム。

> 收錄內容：《JOJO 的奇妙冒險》・《咒術迴戰》（角色名／招式名／術語，題數依 `QUESTIONS` 而定，可持續擴充；首頁顯示的題數會自動更新）
> 本作為非官方學習用同人作品，所有登場人物與技名等版權歸原作品所有。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可遊玩（不需安裝、不需伺服器）。

## 程式檢查與版面建議

使用 Node.js 內建測試工具，不需安裝套件：


## 多語介面

- 介面可在**日本語／繁體中文**之間切換：標題列的「中文／日本語」按鈕，或是「設定 → 言語」的切換鈕；進度與語言偏好分開保存，重置進度不影響語言
- 繁中瀏覽器（zh-TW / zh-HK / zh-CN…）**首次開啟自動顯示中文**，不需手動設定
- 遊戲中切換語言**立即重新渲染**（題目提示、按鈕、結算、任務、收藏冊、五十音表全數跟上）
- 題目線索也附中文對照（如「史密斯飛船的使者。」→ ナランチャ），完全不懂日文也能玩
- 注意：內容（假名、漢字、朗讀發音）固定是日語的，這正是學習本體

## 玩法與模式

| 模式 | 說明 |
|------|------|
| ききとりチャレンジ（聽音挑戰） | **首頁「馬上開始玩」的預設玩法**。不限時；聽讀音，把打散的假名照正確順序排回去（拼字玩法，不是選擇題）。自動朗讀答案，可隨時按「聽讀音」重播。答錯失去 1 顆愛心，**愛心共 3 顆，用完就結束；零限制連擊**（連勝紀錄與其他模式共用）|
| ならべかえ れんしゅう | 自由練習。可選作品（JOJO／咒術迴戰／全部）、難度（Lv.1〜3）、文字（平假名／片假名）|
| タイムアタック | 60 秒限時作答，依等級給分，可獲得星星與最佳成績紀錄 |
| デイリーチャレンジ | 每日 5 題（依日期固定題組），當日首次完成可得 +50 XP・星星・連續天數紀錄。重玩保留逐題 XP／金幣，通關加碼每日限領一次 |
| ごじゅうおん表 | 平假名／片假名對照表，點一下會發音（含濁音、拗音）|
| コレクション | 累計正解數或コインガチャ解鎖 12 張收藏卡（3 張ノーマル、4 張レア、5 張 SSR）|
| ミッション | 12 個任務，按頂欄鈴铛進入；完成可直接領取金幣獎勵 |

規則：把打亂的假名タイル依正確順序點選填入格子；「・」固定不動。填滿後自動判定。答錯會抖動並把タイル退回，答對時會朗讀假名。
已點選的假名タイル不會消失，而是**反白（亮底深字）**，一眼就能看出哪些假名已經選過。

備註：每日挑戰會**排除最近 7 天**已出過的題目（以 2026-01-01 為起算點，逐日遞迴決定題組，結果可重現），長期遊玩也不容易重複。

| 🎁 おたからボックス | 120 金幣開箱（12% 概率卡内容随机）：3 段敲箱動畫→隨機解鎖未取得卡片（集完變 +150 XP 包）；全息 SSR 光效 |

## 學習設計

- 每題以**原文漢字＋羅馬字＋假名**三種形式揭曉，邊玩邊認字
- XP・プレイヤーランク（五十音みならい→傳説の日本語つかい）、連續正解（れんさ）與最高紀錄
- **音声パック（Fish Audio）**：59 題共用 58 個假名讀音 MP3 音檔（`assets/voice/*.mp3`，約 1.4 MB）。作品別音色與語氣：JOJO → `5a8e46f1b94c4351aebb8a66b113cec5`（平順朗讀）；呪術廻戦 → `827be896a6954a8199ce4b2baad6af36`（**[shouting] 喊技語氣**，像叫招式一樣大聲，不像平鋪念稿）。模型：`s2.1-pro-free`；溫度／語速：JOJO 0.92x、呪術廻戦 1.0x。播放遵循「設定 → よみあげ音声」開關；檔案缺失或播放失敗時自動切換為瀏覽器語音合成（ja-JP）
- Web Audio API 合成音效 + 瀏覽器語音合成（ja-JP）朗讀（語音パックが無い場合のフォールバック）
- 可選 MP3 音效優先使用 `assets/sfx/` 的同名檔案，缺檔回到既有合成音效；`assets/bgm/` 預留首頁、一般遊玩、限時挑戰三首循環音樂，缺檔保持安靜。背景音樂、音效、朗讀皆可獨立開關
- 進度（XP・星星・卡牌・每日挑戰紀錄）保存在瀏覽器 localStorage

## 加題目

在 `js/data.js` 的 `QUESTIONS` 陣列新增一筆即可：

```js
{ id: 'q60', anime: 'jjk', type: 'char',      // anime: jojo | jjk；type: char | waza | term
  label: '禪院真希',                          // 揭暁時顯示的原文
  kana: 'ゼンインマキ',                        // 片假名（平假名模式會自動轉換）
  en: 'Zenin Maki', desc: '禪院家の術師。',   // ローマ字ヒント／作答時顯示的提示
  level: 2 },                                  // 1=やさしい / 2=ふつう / 3=むずかしい
```

「・」會被視為固定字元不參與洗牌；其餘假名（含促音・長音・拗音小字）都會打散。

新增題目後若要補上音声パック（可選；沒有檔案也能用瀏覽器語音，只是音色是機械音）：

```bash
# 需要 Fish Audio 帳號與 API Key（環境変数 FISH_API_KEY）
node tools/generate-voice-pack.js                 # 全部（既存ファイルはスキップ）
node tools/generate-voice-pack.js --only=jjk --force   # 呪術廻戦だけ作り直す（[shouting] 語氣）
node tools/generate-voice-pack.js --only=jojo --force  # JOJOだけ作り直す
```
