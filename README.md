# 五十音クエスト（五十音大冒險）

[線上遊玩](https://yorkwahaha.github.io/gojuon-quest/) · [GitHub 原始碼](https://github.com/yorkwahaha/gojuon-quest)

アニメのキャラクター名・わざ名をならべかえて、ひらがなとカタカナを楽しく覚える 小学生向け日本語学習ゲーム。

> 收錄內容：《JOJO 的奇妙冒險》・《咒術迴戰》（角色名／招式名／術語，題數依 `QUESTIONS` 而定，可持續擴充；首頁顯示的題數會自動更新）
> 本作為非官方學習用同人作品，所有登場人物與技名等版權歸原作品所有。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可遊玩（不需安裝、不需伺服器）。

## 程式檢查與版面建議

使用 Node.js 內建測試工具，不需安裝套件：

```bash
node --test
node --test --experimental-test-coverage
```

測試使用受控 DOM、時鐘與音訊替身，驗證測驗／存檔／寶箱的邏輯；不代表真實瀏覽器、手機、發音或視覺驗收。

## 多語介面

- 介面可在**日本語／繁體中文**之間切換：標題列的「中文／日本語」按鈕，或是「設定 → 言語」的切換鈕；進度與語言偏好分開保存，重置進度不影響語言
- 繁中瀏覽器（zh-TW / zh-HK / zh-CN…）**首次開啟自動顯示中文**，不需手動設定
- 遊戲中切換語言**立即重新渲染**（題目提示、按鈕、結算、任務、收藏冊、五十音表全數跟上）
- 題目線索也附中文對照（如「史密斯飛船的使者。」→ ナランチャ），完全不懂日文也能玩
- 注意：內容（假名、漢字、朗讀發音）固定是日語的，這正是學習本體

## 玩法與模式

| 模式 | 說明 |
|------|------|
| ききとりチャレンジ（聽音挑戰） | **首頁「馬上開始玩」的預設玩法**。不限時；聽讀音，把打散的假名照正確順序排回去。可選作品與難度。自動朗讀題目，可按「聽讀音」重播。若發音已關閉，可在開始畫面開啟或改玩自由練習。答錯失去 1 顆愛心，**愛心共 3 顆，用完就結束**（連勝紀錄與其他模式共用）。 |
| ならべかえ れんしゅう | 自由練習。可選作品（JOJO／咒術迴戰／全部）、難度（Lv.1〜3）、文字（平假名／片假名）|
| タイムアタック | 60 秒限時作答，依等級給分，可獲得星星與最佳成績紀錄 |
| デイリーチャレンジ | 每日 5 題（依日期固定題組），當日首次完成可得 +50 XP・星星・連續天數紀錄。重玩保留逐題 XP／金幣，通關加碼每日限領一次 |
| ごじゅうおん表 | 平假名／片假名對照表，點一下會發音（含濁音、拗音、促音／長音例詞及外來語組合）|
| コレクション | 累計正解數或コインガチャ解鎖 12 張收藏卡（3 張ノーマル、4 張レア、5 張 SSR）|
| ミッション | 12 個任務，按頂欄鈴铛進入；完成可直接領取金幣獎勵 |

規則：把打亂的假名タイル依正確順序點選填入格子；「・」與「＆」固定不動。填滿後自動判定。答錯會抖動並把タイル退回，答對時會朗讀假名。
已點選的假名タイル不會消失，而是**反白（亮底深字）**，一眼就能看出哪些假名已經選過。

備註：每日挑戰會**排除最近 7 天**已出過的題目（以 2026-01-01 為起算點，逐日迭代決定題組，結果可重現），按題目 ID 排除，並非按讀音排除。全部模式按題目均勻抽樣，JOJO 86 題、咒術 25 題；不保證作品各半。

## 學習設計

- 題目提示使用忠實對應假名的羅馬字（長音重複母音）；揭曉顯示原文、假名與原語／英文名稱，兩者分開處理
- XP・プレイヤーランク（五十音みならい→傳説の日本語つかい）、連續正解（れんさ）與最高紀錄
- **預錄語音**：111 題共用 110 個經 Fish Audio 生成的 MP3（`assets/voice/*.mp3`，約 2.64 MB）。JOJO 角色依陣營使用對應聲線，替身名與招式使用喊技語氣。呪術廻戦沿用既有喊技聲線。播放遵循「設定 → よみあげ音声」開關。
- 14 種遊戲音效使用 `assets/sfx/` 的 MP3，缺檔、播放失敗或逾時時略過。題目朗讀使用語音包，備援為瀏覽器語音合成（ja-JP）。
- `assets/bgm/` 預留首頁、混合題、混合限時、JOJO、咒術迴戰五首循環音樂。單選作品時立即使用該作品 BGM（含限時模式），缺檔保持安靜。背景音樂、音效、朗讀皆可獨立開關。完整圖片招式、JOJO 第 2／3／4 部題庫與補檔路徑見 [媒體清單](docs/MEDIA-CATALOG-2026-11-17.md)。
- 進度（XP・星星・卡牌・每日挑戰紀錄）保存在瀏覽器 localStorage。支援 Web Locks 的瀏覽器同時只有一個分頁可寫入；其他分頁會顯示提示。無 Web Locks 時仍檢查存檔變更並阻止舊分頁覆蓋。存檔損毀時會保留原始資料並顯示提醒。

## 加題目

在 `js/data.js` 的 `QUESTIONS` 陣列新增一筆即可（題號不可與既有 q60～q111 重複）：

```js
{ id: 'q112', anime: 'jjk', type: 'char',      // anime: jojo | jjk；type: char | waza | term
  label: '禪院真希',                          // 揭暁時顯示的原文
  kana: 'ゼンインマキ',                        // 片假名（平假名模式會自動轉換）
  en: 'Zenin Maki', desc: '禪院家の術師。',   // ローマ字ヒント／作答時顯示的提示
  level: 2 },                                  // 1=やさしい / 2=ふつう / 3=むずかしい
```

「・」會被視為固定字元不參與洗牌；其餘假名（含促音・長音・拗音小字）都會打散。

新增題目後若要補上音声パック（可選；沒有檔案也能用瀏覽器語音，只是音色是機械音）：

```bash
# 需要 Fish Audio 帳號與 API Key（環境変数 FISH_API_KEY）
node tools/generate-voice-pack.js                 # 只生成缺少或內容過期的檔案
node tools/generate-voice-pack.js --only=jjk --force   # 呪術廻戦だけ作り直す（[shouting] 語氣）
node tools/generate-voice-pack.js --only=jojo --force  # JOJOだけ作り直す
```

## 存檔、跨日與語音維護

- 每日場次以實際開始的題組日期計算。通關日期與獎勵一併儲存，寫入失敗可再按結算重試。已領過或更舊的日期不重領。
- 限時模式以最後一塊填入當下判題，設定視窗開啟時倒數仍繼續。自動切題後，已啟動的喊技可繼續播放，鍵盤焦點會從下一題按鈕移到新題的字塊。
- 一般朗讀與招式喊技直接播放同站 MP3。播放失敗或 4 秒未啟動時，改用瀏覽器日語 TTS。聽音挑戰在語音開始播放後才開放字塊，語音失敗時可重播或前往自由練習。五十音表中未收錄在語音包的讀音也使用瀏覽器 TTS。
- 公開 Worker 的 `/api/voice` 將白名單內的已錄製讀音轉址到版本化靜態音檔。生成只在明確執行本機維護命令時進行。
- `node tools/voice-server.js` 啟動本機預覽。前端直接播放音檔，本機 `/api/voice` 也可提供既有音檔。可公開檔案限 index、CSS、JS 與素材。
- 聲線和語氣配置見 `tools/voice-config.cjs` 與 `tools/voice-style.cjs`。生成器用讀音、模型、聲線與語氣指紋判定是否要重產，確認 MP3 可解碼後才替換。音檔 URL 帶內容 hash。
- 補上 BGM 或音效後，執行 `node tools/generate-voice-pack.js --media-only` 更新素材清單，再與音檔一起提交。`--sync-only` 也會同步既有朗讀音檔與 Worker 白名單，兩個命令均無需 API key。
- 僅生成指定題號：`node tools/generate-voice-pack.js --ids=q82,q99,q106,q110,q111`。實際生成才需要環境變數 `FISH_API_KEY`，並使用 ffmpeg 驗證可解碼性。
- 可選 Chromium 驗證可用 `node tools/browser-smoke.cjs` 與 `node tools/browser-voice-smoke.cjs`。共享執行環境可用 `PLAYWRIGHT_MODULE` 指定 `playwright-core`，並用 `PLAYWRIGHT_EXECUTABLE_PATH` 指定已安裝的 Chromium。

卡片與玩家階級是遊玩獎勵，並非兩種假名均已精通的能力認證。聲音關閉或裝置沒有日語 TTS 時，需開啟發音或使用可播放語音包的瀏覽器。
